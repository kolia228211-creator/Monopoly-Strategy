2. Створи закладку (Chrome на Android)

  1. Відкрий будь-яку сторінку (хоч цю) → ⋮ → натисни ☆, щоб додати закладку.
  2. Унизу з'явиться «Закладку додано» → Змінити (або ⋮ → Закладки → довге натискання → Змінити).
  3. Назва: RU. У полі URL стери все й встав скопійований код. Збережи.

3. Запиши гру

  1. Зайди в кімнату на richup.io (краще ще до «Start Game»).
  2. Торкнися адресного рядка, набери RU і вибери закладку з зірочкою (не пошук Google!).
  3. Унизу ліворуч з'явиться панелька ● REC. Грай як завжди. Бажано, щоб у грі були: купівля, аукціон, обмін, будинки, іпотека, тюрма.
  4. У кінці (або коли гра тобі набридне) натисни 💾 (зберегти) або 📤 (поділитися). Надішли файл Claude в чат.

⚠️ Не оновлюй сторінку під час запису: дані зберігаються тільки до перезавантаження. Якщо панелька зникла, просто запусти закладку ще раз.
