Записувач гри richup.io

Записує одну партію, щоб помічник навчився розуміти сайт. Нічого не натискає в грі, токени й паролі маскуються, файл лишається в тебе.

1Скопіюй код

Розмір: {{SIZE_KB}} КБ. Якщо кнопка не спрацювала, утримуй палець у полі вище → «Вибрати все» → «Копіювати».

2Створи закладку в Chrome

  1. Відкрий будь-яку сторінку в Chrome → ⋮ → ☆, щоб додати закладку.
  2. Відкрий ⋮ → Закладки, утримуй щойно додану закладку → Змінити.
  3. Назва: RU. Поле URL очисти повністю, встав скопійований код і збережи.

3Запиши партію

  1. Зайди в кімнату на richup.io, бажано ще до натискання «Start Game».
  2. Торкнися адресного рядка, набери RU і вибери закладку із зірочкою, а не пошук Google.
  3. Унизу ліворуч з'явиться панелька ● REC. Грай як зазвичай. Найкорисніше, щоб у партії були купівля, аукціон, обмін, будинки, іпотека й тюрма.
  4. Наприкінці натисни 💾, щоб зберегти файл, або 📤, щоб поділитися ним. Надішли файл у чат Claude.

Не оновлюй сторінку під час запису: дані живуть до перезавантаження. Якщо панелька зникла, просто запусти закладку ще раз.

4На комп'ютері

Те саме: створи закладку з назвою RU, встав код у поле адреси й натискай її на сторінці гри.
