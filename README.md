# 🎲 Monopoly-Strategy: помічник для richup.io

Панель поверх гри на [richup.io](https://richup.io), яка в реальному часі підказує найкращі дії: купувати чи ні, скільки ставити на аукціоні, чи приймати обмін і яка максимальна доплата, куди ставити будинки, що закладати при нестачі грошей. Також показує **шанси на перемогу** кожного гравця і як їх змінить твоє рішення.

Помічник **лише читає** стан гри. Він нічого не надсилає на сервер і нічого не натискає за тебе.

## Встановлення

### Телефон (Chrome на Android) і ПК: закладка
1. Скопіюй код із файлу [`dist/helper.bookmarklet.txt`](dist/helper.bookmarklet.txt) або на сторінці встановлення.
2. Створи закладку з назвою `RU` і встав код у поле URL.
3. У кімнаті richup.io набери `RU` в адресному рядку та вибери закладку.

Закладка щоразу бере **найновішу версію** з цього репозиторію (останній коміт → jsDelivr).

### ПК: розширення Chrome (запускається само)
1. [Завантаж ZIP](https://github.com/kolia228211-creator/Monopoly-Strategy/archive/refs/heads/main.zip) і розпакуй.
2. `chrome://extensions` → **Режим розробника** → **Завантажити розпаковане** → папка `extension`.

Розширення теж підтягує свіжу версію з GitHub, а якщо мережа недоступна, використовує вбудовану копію.

## Що показує панель

| Ситуація | Порада |
|---|---|
| Став на вільну ділянку | КУПУЙ / Аукціон + максимальна ставка, цінність ділянки, шанс перемоги «купиш» проти «віддаси» |
| Аукціон | Став / Пас, твій максимум, скільки готові дати суперники |
| Обмін | ПРИЙМАЙ / ВІДХИЛЯЙ, шанс перемоги після обміну, максимальна доплата, мінімальна ціна продажу |
| Повний набір | порядок будинків, вартість доведення до 3 будинків, дохід за коло, окупність |
| Борг | що продати чи закласти, щоб втратити найменше доходу |
| Тюрма | платити $50 чи сидіти |
| Завжди | шанси всіх гравців, ідеї обмінів, небезпека наступного кидка й безпечний запас |

## Навчання

Помічник запам'ятовує, як грає кожен суперник (за нікнеймом або акаунтом):
- **аукціони:** до якої частки ціни доходить (медіана й 75-й перцентиль);
- **купівлі:** як часто купує, а як часто віддає на аукціон;
- **обміни:** на які погоджується і з якою мінімальною вигодою;
- **будинки й застави.**

Після 2+ спостережень ці дані враховуються в порадах: оцінка ставок суперників на аукціоні, підказки при купівлі, шанси, що твій обмін приймуть.

**Журнал партій** зберігає події, твої рішення разом із порадою й шансом у той момент, а також результат. Кнопка «⤓ журнал» у панелі зберігає все у файл, «⤒» завантажує його на іншому пристрої (наприклад, з телефона на ПК). Розібрати журнал: `npm run journal -- файл.json`. За цими розборами поради доопрацьовуються, а оновлення приходять автоматично.

Усе зберігається лише у твоєму браузері.

## Як це працює

- Стан гри береться з клієнтського Zustand-сховища richup (див. [`docs/PROTOCOL.md`](docs/PROTOCOL.md)).
- Правила richup відтворені з коду гри: x2 оренда на повному наборі, START +300/+200, Vacation забирає хід, вихід з тюрми $50, рівномірна забудова, правило «чесного» обміну в публічних кімнатах.
- Частоти потрапляння на клітинки рахуються симуляцією по справжній дошці з картками.
- Шанси на перемогу: Монте-Карло догравання партії (~250 партій) від поточного стану, у фоні, без гальмування сторінки.
- Оцінки обмінів і аукціонів спираються на формули з математичного звіту ([`sim/`](sim/)).

## Структура

```
src/helper/     помічник: rules, probability, advisor, sim, learn, ui, main
src/loader/     завантажувач (закладка й розширення)
src/recorder/   записувач протоколу (крок 1, для розробки)
extension/      розширення Chrome (Manifest V3)
dist/           зібрані файли (роздаються через jsDelivr)
data/           справжні дані дошки Classic (оренди, картки, правила)
docs/           протокол і сторінка встановлення
sim/            математика: Марковський ланцюг, Монте-Карло, PDF-звіт
tools/          збірка й тести
```

## Розробка

```bash
npm install
npm run build   # src -> dist/, extension/, docs/index.html
npm test        # рушій (Node) + записувач і панель у Chromium (потрібен playwright)
```

Після `git push` закладка та розширення підхоплюють нову версію автоматично.
