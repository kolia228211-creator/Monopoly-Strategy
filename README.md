# 🎲 Monopoly-Strategy: помічник для richup.io

Помічник для гри в Монополію на [richup.io](https://richup.io), схожий на аналіз у lichess: дивиться на гру в реальному часі й підказує найкращу дію. Купувати чи ні, скільки ставити на аукціоні, чи вигідний обмін і яка максимальна ціна, куди ставити будинки, коли бракує грошей, і які шанси на перемогу.

Налаштування, під які все рахується: мапа **Classic**, старт $1500, аукціон ✅, vacation cash ✅, іпотека ✅, рівномірна забудова ✅, у тюрмі оренду **збирають**, 3–6 гравців.

## Встановлення записувача (крок 1)

👉 **Сторінка встановлення:** https://kolia228211-creator.github.io/monopoly-strategy/

Коротко для Chrome на Android:
1. На сторінці встановлення натисни «Скопіювати код».
2. Додай будь-яку сторінку в закладки, потім зміни цю закладку: назва `RU`, у полі URL встав код.
3. У кімнаті richup.io набери `RU` в адресному рядку та вибери закладку. Унизу з'явиться **● REC**.
4. Зіграй гру, натисни 💾 або 📤 і надішли файл Claude.

## Етапи

| # | Етап | Статус |
|---|------|--------|
| 1 | **Записувач**: зрозуміти, як richup.io передає стан гри (WebSocket, стан Vue/React) | ✅ готовий, чекає на перший запис |
| 2 | **Модель гри**: парсер повідомлень → `GameState` (гравці, гроші, власність, будинки, торги, аукціон) | ⏳ після запису |
| 3 | **Мозок**: Монте-Карло-симуляції + ймовірності (Марковський ланцюг) з точними правилами richup | ⏳ паралельно йде окрема сесія з математикою |
| 4 | **Помічник**: панель поверх гри з порадами українською та % шансу на перемогу | ⏳ |
| 5 | **Оновлення**: закладка-завантажувач підтягує свіжу версію з GitHub автоматично | ⏳ |

## Структура

```
src/recorder/      записувач гри (bookmarklet)
data/              дані дошки (ціни, групи, пізніше оренди та картки)
docs/              сторінка встановлення (GitHub Pages), генерується збіркою
dist/              зібрані файли
tools/             збірка й тести
sim/               симулятор і математика (окрема сесія)
```

## Розробка

```bash
npm install
npm run build   # src -> dist + docs/index.html
npm test        # тест записувача в Chromium (потрібен playwright)
```
